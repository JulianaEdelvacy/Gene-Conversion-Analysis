# Gene Conversion Analysis

![GitHub language count](https://img.shields.io/github/languages/count/julianaedelvacy/Gene-Conversion-Analysis)


This repository provides a comprehensive set of scripts in R and Python for the analysis and plotting of Gene Conversion (GC) events. The workflow is designed to process the output generated by the Brepconvert software, allowing for data filtering, analysis, and the visualization of key results. For details on generating the primary input table using the Brepconvert software, please consult the official page: https://github.com/Fraternalilab/BrepConvert/.

## 📋 Prerequisites and Dependencies
To run the codes, you must have Python 3 and R installed on your system.

## 1. File Requirements
To execute the core analysis scripts, you need to provide the following input files:

* Brepconvert Output Table: The main table generated by Brepconvert containing GC event annotations.
* IMGT-gapped-nt-sequences: The IMGT-gapped nucleotide sequences that served as input for Brepconvert.
* Non-B Motif Data (Optional): A table (text or TSV) containing the positions of non-B structural motifs (e.g., Direct Repeats), required only for the Non_b_motifs_analysis.r script.

Note: Example input files for testing the workflow are available in the test_files/ directory.

## 🗂️ Structure and Execution Order

The analysis is divided into three functional stages. The R scripts can be executed via the command line or using Rstudio.

### 1. Optional: Sequence Filtering Scripts (Python)


| File  | Description |
| ------------- | ------------- |
| Python/Phred_Score_Filter.py  | Filters input FASTQ sequences based on Phred quality scores prior to Brepconvert annotation. |

### 2. Core Data Treatment (Mandatory Order)
These files must be executed in sequence to ensure proper data cleaning, filtering, and preparation.

| File  | Description |
| ------------- | ------------- |
| R/1-Prepare_data_for_gene_order_filter.r  | Prepares the output data of Brepconvert for gene order filter. |
| R/2-Gene_Order_Filter.ry  | Applies the gene order filter, retaining only pseudogenes that are before a functional gene. Primary output: final_result_filtered.csv. |
| R/3-Data_analysis.r  | Performs analysis of filtered data characteristics. |

### 3. Visualization and Plotting Scripts

| File  | Description |
| ------------- | ------------- |
| R/ChordDiagram.r  | Generates a Chord Diagram visualizing the donor-acceptor relationships of the gene conversion events. |
| R/Non_b_motifs_analysis.r  | Generates a scatter plot comparing the position of GC events against Non-B motifs. |

## 🚀 Usage Workflow

First, clone the repository using the following command:

```
git clone https://github.com/JulianaEdelvacy/Gene-Conversion-Analysis
```
### Step 1: Core Data Treatment (Rscript)

Assuming your input files (Brepconvert output, IMGT sequences, etc.) are located in a directory named test_files.

```
# The first argument specifies the directory containing the input files.

# 1. Data Preparation
Rscript R/1-Prepare_data_for_gene_order_filter.r test_files

# 2. Apply Gene Order Filter
# This script generates 'final_result_filtered.csv' in the current working directory ('.').
Rscript R/2-Gene_Order_Filter.r .

# 3. Final Analysis and Aggregation
Rscript R/3-Data_analysis.r .

```

### Step 2: Visualization and Plotting

```
# Generate the Chord Diagram (Outputs Rplots.pdf)
Rscript R/ChordDiagram.r .
```
