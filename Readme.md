# Gene Conversion Analysis 
![GitHub last commit (branch)](https://img.shields.io/github/last-commit/julianaedelvacy/Gene-Conversion-Analysis/main)
![GitHub language count](https://img.shields.io/github/languages/count/julianaedelvacy/Gene-Conversion-Analysis)


Codes in R and Python  used to analyze and plot the output generated by Brepconvert software.
Details on how to use the Brepconvert software are available on the official page https://github.com/Fraternalilab/BrepConvert/.
There is one file for sequence filtering (optional), three files used for sequence analysis, and three for plotting graphics.

## Files for Sequence Filtering (Optional)
- Phred_Score_Filter.py

## Files for treating the data should be used in the following order:
- 1-Prepare_data_for_gene_order_filter.r 
- 2-Gene_Order_Filter.r
- 3-Data_analysis.r
	
## Files for plotting the treated data:

- ChordDiagram.r
- Non_b_motifs_analysis.r
- Gene_conversion_percentage.py

## Files Requirements:

To run the codes, you should have an output table generated by Brepconvert, and we also recommend having the IMGT-gapped-nt-sequences used as input for Brepconvert.
For testing, you can use the example output files in the paste test_files.

## Usage

Download the codes using the following command.
Make sure you have also installed Python and Rstudio on your computer.

```
git clone https://github.com/JulianaEdelvacy/Gene-Conversion-Analysis
```
