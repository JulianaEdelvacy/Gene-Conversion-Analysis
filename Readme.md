# Gene Conversion Analysis

Codes in R and Python used to analyze and plot the output generated by Brepconvert software.
Details on how to use the Brepconvert software is available in the official page https://github.com/Fraternalilab/BrepConvert/.
There are four files used for sequence analysis and plotting the graphics. 

For R files they are numbered in the suggested order of use for the analysis, from 1 to 3.
