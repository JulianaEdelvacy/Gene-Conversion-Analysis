# Gene Conversion Analysis

Codes in R and Python used to analyze and plot the output generated by Brepconvert software.
Details on how to use the Brepconvert software is available in the official page https://github.com/Fraternalilab/BrepConvert/.
There are three files used for sequence analysis and three for plotting graphics. 

## Files for treating the data, should be used in the following order:
- 1-Prepare_data_for_gene_order_filter.r 
- 2-Gene_Order_Filter.r
- 3-Data_analysis.r
	
## Files for plotting the treated data:

- ChordDiagram.r
- Non_b_motifs_analysis.r
- Gene_conversion_percentage.py

For using the files you should have an output table gerated by Brepconvert.
